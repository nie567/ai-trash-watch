### 步骤 4：配置项目结构
如果 IDEA 识别不出 Java 源码目录，手动设置：

1. 右键点击 `src\main\java` → `Mark Directory as` → `Sources Root`
2. 右键点击 `src\main\resources` → `Mark Directory as` → `Resources Root`
3. 右键点击 `src\main\webapp` → `Mark Directory as` → `Web Resources Root`
4. 右键点击 `src\test\java` → `Mark Directory as` → `Test Sources Root`

### 步骤 5：配置 Artifacts（部署用）
1. `File` → `Project Structure` → `Artifacts`
2. 点击 `+` → `Web Application: Exploded` → `From Modules`
3. 选择你的模块
4. 确保输出目录指向 `target\user-management`

### 步骤 6：配置运行
1. `Run` → `Edit Configurations`
2. 点击 `+` → `Tomcat Server` → `Local`

4. 点击 `OK`

在 MySQL 中执行 `src\main\resources\schema.sql`
